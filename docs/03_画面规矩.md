# 03 画面规矩

## 从风格库选，按题材定细节
- 画风先从 [07_风格库.md](07_风格库.md) 里按题材选；选定后再定这期的核心意象和配色，颜色最好**从题材里取**（第28期：克劳德橙 = 反蒸馏、英伟达绿 = 算力，都是压力来源的品牌色）。
- 同一风格连续两期用，要换配色和主线物件。
- 参考项目只学方法。第5期用了现成的像素 RPG 风格，一半理由是省事，被评"取巧、成片质量太差"。

## 真实素材优先
- **不用 AI 生成图**（第5期 Seedream 写实图被评"AI 味太重"）。
- 能用视频就用视频；照片别一张不动只靠动效撑；段落之间用空镜过渡。
- 人物和事件：整张新闻照片/视频 + 图注，比抠图更可信。
- 英文重点就地换中文高亮（`webhl.mjs` 的 `zhin` / `zhover.js`）。

## 主线要往前走
- 先画主线路径：全片是一条往前走的路，每段落在一个新地方，用走线/镜头平移/上一张缩成下一张的一部分来过渡。
- 母版画面（总图、时间轴）最多出现 2–3 次（第13期反复回到总图，被评"没有主线过渡感"）。
- 相邻两段不能是同一种画面语言；同一种界面最多占 30% 时长。

## 不要的东西
- PPT 式居中卡片排数字、鼠标光标、全片压暗、整段文字铺满屏（第19、27期）。
- 意象比喻搭出来的"世界"（第12期分账单/聊天窗口/蓄水池都被否）。确实需要比喻时，只用真实小物件，先征得同意（第28期练习册）。
- 绿幕抠像（第25期被评"好奇怪"）。

## 账号统一项
- 1080×1920、30fps；右上角角标「AI来龙去脉」；底部细进度条。
- 字幕：只有中文，白字黑描边，一屏 ≤14 字按逗号切；关键词上色（这期的颜色）。
- 无配乐、无音效；不做左上角章节标签；无底部来源小字（来源写在画面标签里，如「Anthropic 官方博客 · 2026-02-23」）。

## 关键帧要终稿画质
- 关键帧就是成片里的那一帧，有光影、纸纹、阴影，不是平涂草图（Pillow 平涂被评太简陋）。
