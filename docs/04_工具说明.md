# 04 工具说明

所有脚本都在**本期目录**下运行（`examples/ep28_distill_shicong/` 或 `episodes/epXX/`），路径相对本期目录；外部程序和密钥从环境变量读（`tools/cfg.py`、`film/cfg.mjs`、`.env.example`）。

## tools/（Python / Shell）

| 脚本 | 作用 | 用法 | 输出 |
|---|---|---|---|
| `cfg.py` | 公共配置：本期目录、ffmpeg、Whisper 模型、字体 | 被其他脚本 import | — |
| `doubao_tts.py` | 豆包语音合成 2.0 客户端（HTTP 单向流式） | `tts(text, speaker, out, rate)` | mp3 |
| `tts.py` | 读 `文案_定稿.md`，一段一句合成，去头尾静音 | `python tools/tts.py [句号…]`（带句号=只重配这几句） | `tts/NN.mp3`、`tts/meta.json` |
| `words_all.py` | faster-whisper 逐字识别每句配音，拼音比对文案，多字少字都打印 | `python tools/words_all.py [句号…]` | `tts/words.json` |
| `gen_timeline.py` | 按 `SC`（每句怎么切屏）把逐字时间映射成字幕屏；`NUMS` 处理识别成阿拉伯数字的地方 | `python tools/gen_timeline.py` | `tts/timeline.json`、`film/timeline.js` |
| `prep.mjs` | 按 `film/shots.js` 抽视频帧：`full` 竖屏裁切（`cx` 中心、`ch` 裁高躲台标）、`rot` 旋转、`blur` 虚化 | `node tools/prep.mjs [镜头id…]`（带 id=强制重抽） | `film/seq/<id>/NNNN.jpg`、`film/seqinfo.js` |
| `score.py` | 配音按时间轴铺进音轨，-14 LUFS 响度标准化、结尾淡出 | `python tools/score.py out.wav` | wav |
| `build_v1.sh` | 全片：两路并行渲染 → 拼接 → 音轨 → 成片 | `bash tools/build_v1.sh` | 成片 mp4 |
| `patch.sh` | **局部补渲**：只渲指定秒段，按帧替换进画面母版，核对帧数，再配原音轨 | `bash tools/patch.sh 43.9 48.1 [5.3 6.95 …]` | 覆盖成片 |
| `dull_scan.py` | 闷点扫描：10fps 小灰度图，去掉字幕带/角标/进度条，对每个起点看 2 秒内最大变化 | `python tools/dull_scan.py 成片.mp4 [阈值=3.0]` | 闷段列表、`DULL_SEGS n` |
| `final_qc.py` | 成片字幕对时：从成片抽音轨重新识别，每屏字幕时间段里识别到的字和屏上的字按拼音比 | `python tools/final_qc.py 成片.mp4` | 每屏 OK/BAD |
| `fsheet.py` | 视频缩略图总览（输入端跳着抽，不整条解码） | `python tools/fsheet.py 视频 张数 out.jpg [起 止]` | jpg |
| `grid.py` | 把检查帧拼成网格 | `python tools/grid.py out.jpg 帧1.jpg 帧2.jpg …` | jpg |
| `doubao_qa.py` | 同一道题让两个模型各答一遍，原样存档（第 6 句素材） | `python tools/doubao_qa.py 大模型 小模型` | `资料/豆包实测/*.json` |
| `fetch_assets.sh` | 本期全部素材的获取记录（视频、空镜、网页、发布页、抽帧、字体、npm） | `bash tools/fetch_assets.sh` | `素材/`、`film/img/`、`film/seq/` |

## scripts/（仓库级）

| 脚本 | 作用 |
|---|---|
| `new_episode.sh ep29_xxx [成片名]` | 从第28期拷一套通用工具到 `episodes/ep29_xxx/`，清空每期要重写的部分 |
| `sync_rules.sh` | 从 `AGENTS.md` 生成 `CLAUDE.md`、`GEMINI.md`、`.cursor/rules/ai-laimai.mdc` |

## film/（浏览器渲染）

| 文件 | 作用 |
|---|---|
| `kit.js` | 本期颜色 `C`、字体、`div/img` 工具、纸底 `paper()`、实拍 `footage()`、字幕 `caption()`、角标进度条 `hud()`、印章 `stamp()` |
| `kf.js` | 关键帧 `renderKF(n)`；时间轴数据 `LANES`（发布点）、`FLAGS_OR/FLAGS_GR`（两色压力事件）、`timeline()` |
| `shots.js` | 镜头表：`sh(id, 起, 止, {src, ss, m, cx, ch})` |
| `scenes.js` | 全片 `render(t)`：每个镜头一个 `D.<id>(t)`；`camAt(t)` 时间轴相机关键帧；`caps(t)` 按时间轴出字幕 |
| `timeline.js` | `gen_timeline.py` 生成，别手改；`S(n)` 第 n 句开始、`T0(n,k)` 第 n 句第 k 屏开始、`AT(n,'词')` 某个字被念到的时刻 |
| `index.html` / `index_kf.html` | 全片 / 关键帧页面（预加载字体和图片，`window.READY` 后开始截图） |
| `render.mjs` | `node render.mjs stills t1 t2 …` 出单帧；`node render.mjs clip out.mp4 a b` 渲一段无声 30fps 视频 |
| `shot_kf.mjs` | 出关键帧到 `kf/` |
| `webhl.mjs` + `zhover.js` | 网页原句高亮截图：`node webhl.mjs url cuts.json 760`；`NOJS=1` 关页面脚本、`HIDEFIXED=1` 隐藏浮窗 |
| `shot_page.mjs` | 官方发布页页头截图；`WAIT=20000` 等慢页面 |
| `gettext.mjs` / `peek.mjs` | 看页面渲染后的文字 / 手机视口整页截图（找原句、找坐标用） |
| `cuts/*.json` | 每个网页的高亮规则：`ph` 原句、`zhin` 就地换成的中文、`col` 颜色、`h/at` 截图高度和高亮位置 |

## 时间与坐标约定
- 时间一律用成片秒数；字幕和动画都从 `timeline.js` 取（`S/T0/AT`），配音一改，动画自动跟着走。
- 网页截图里的坐标用"原图 1080 宽"的像素，`web()` 返回的 `X()/Y()` 换算成屏幕坐标（随推镜缩放）。高亮位置可以用颜色在图里找（见 06_踩坑记录 的 numpy 片段）。
