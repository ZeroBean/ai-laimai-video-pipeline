# 06 踩坑记录

| 现象 | 原因 | 解决 |
|---|---|---|
| YouTube 下载失败 / 要求登录 | 新版 YouTube 需要 JS 解析 + 风控 | 用新版 yt-dlp（2026.10+）且 PATH 里有 deno；必要时 `--cookies`（只导出 youtube/google 域）。不要自己换客户端绕验证 |
| `yt-dlp --download-sections` 让 ffmpeg 崩 | — | 整条下载再用 ffmpeg 截 |
| yt-dlp 合并失败 | PATH 里没 ffmpeg | 把 ffmpeg 所在目录加进 PATH |
| OpenAI 官网无头浏览器 403 / "This page couldn't load" | 反爬 + 前端水合失败 | `curl` 存档 HTML，加 `<base href>`，`NOJS=1` 关页面脚本再渲染 |
| 新浪页面截图被"发现新版本"浮窗挡住 | position:fixed 弹窗 | `HIDEFIXED=1` |
| SEC 官网拦自动访问 | 要求带联系人 UA | 用公司新闻稿代替；**不要**把自己的邮箱填进 UA |
| Pexels / Pixabay 403 | 反爬 | 用 Mixkit（`assets.mixkit.co/videos/<id>/<id>-1080.mp4`，没有 1080 就 720） |
| Mediame 免费空镜带满屏水印 | — | 别用 |
| 千问博客某些页面截不出来（骨架屏） | SPA 加载失败 / id 不对 | 改用官方发布视频里的标志帧 |
| HF 模型 `createdAt` ≠ 发布日 | 仓库常常提前私有创建 | 发布日以官方公告、更新日志为准 |
| 局部补渲后成片变 25fps、少帧 | concat filter 输出没指定帧率，编码器默认 25 | 输出加 `-r 30 -fps_mode cfr`，拼完核对帧数 |
| 补渲截在淡出中间，元素突然消失 | 补丁范围没盖住过渡 | 补丁止点往后放到动画结束 |
| `pkill -f "某命令"` 把自己的 shell 杀了 | 模式匹配到了当前命令行 | 用 `pgrep` 先看 PID 再 kill，或用任务管理停 |
| 720p 空镜竖屏裁切很糊 | 横版裁竖版放大 2.7 倍 | 能旋转 90° 用的就旋转（螺旋本 → 上端装订的练习册），或只做虚化背景 |
| TTS 数字多读字 | 中文和数字间有空格 | `say()` 里去掉中文/数字之间的空格；型号写进 `SAY` |

## 找网页截图里高亮的坐标
```python
from PIL import Image; import numpy as np
a = np.asarray(Image.open('web_xxx_zh.png').convert('RGB')).astype(int)
m = (abs(a - np.array((0xF4, 0xC3, 0xAE))).sum(2) < 18)   # 高亮色
ys, xs = np.where(m); print(xs.min(), ys.min(), xs.max(), ys.max())
```
