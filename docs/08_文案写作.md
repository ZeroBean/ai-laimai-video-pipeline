# 08 文案：上传口播稿 / 给主题自动写

一期片子有两种开始方式：

| 方式 | 你给什么 | Agent 做什么 | 进入流程的哪一步 |
|---|---|---|---|
| **A. 上传口播稿** | 一篇写好的稿子（`.md` / `.txt`，一句一行） | 原样存成 `文案_用户原稿_v1.md`，**默认不改**，只做事实核对 | ① 核稿 |
| **B. 给一个主题** | 一句话主题 / 一条新闻链接 / 一个问题（例："Anthropic 指控国产 AI 蒸馏"） | 调研 → 选结构 → 写 3 个标题 + 文案 v1 → 自查 → **停下来等你改稿或认可** | ⓪ 写稿 → ① 核稿 |

B 方式写出来的稿子，你认可之后就和 A 方式一样：存成 `文案_定稿.md` 往下走。你改过的地方，Agent 不再改回去。

---

## B 方式：给主题写稿

### 1. 选题检查（写之前先过一遍，不过就提出来）
- **挂钩 AI**：AI 知识、AI 新闻、AI 人物。纯科技/汽车类先确认。
- **有新东西**：最近 1–2 周的新闻、新发布、新数据；或者一个大家天天遇到但说不清原因的现象（"AI 越聊越笨"）。
- **观众在局里**：和普通用户有关（免费额度、会员、用法），或者有反差（"免费开源才是最狠的生意"）。
- **少谈股价**：落到产品、技术、事件经过、财报里的营收数字。

### 2. 调研 → `资料/选题调研.md`
- 列 5–10 条来源：官方公告/博客/文档 > 一手媒体报道 > 二手转载。每条写：标题、日期、链接、能用的原话或数字。
- 同一事实多个日期/数字时，以官方为准，差异写下来。
- 找出这条新闻里**最反直觉的一点**，它就是钩子。

### 3. 选结构（从你写过的稿子里归纳）

| 结构 | 骨架 | 例子 |
|---|---|---|
| **新闻型** | 钩子（大反转/爆料）→ 发生了什么（谁、做了什么、一个数字）→ 各方反应 → "不过"转折 → 关键约束 → 结尾问题 | 第24期《大反转！老黄要杀回来了？》 |
| **解释型** | 钩子现象 → 反常的地方 → "只说对了一半" → 更深一层的原因 → 以前 vs 现在的对比 → 这笔账怎么算 → 结尾问题 | 第26期《DeepSeek 限额，免费 AI 到头了？》 |
| **方法型** | 一句引语当钩子 → 权威人物的说法 → "最值得改的就三个" → 第一/第二/第三（每条带一个日常例子）→ 收尾 + 互动 | 第27期《你教 AI 那一套，其实过时了》 |
| **核查型** | 一个流行说法当问题 → 背景 → 名词解释 + 例子 → 双方说法（指控 / 回应）→ 把数据摆出来检验 → 另一个原因 → 开放问题 | 第28期《国产 AI，师从美国？》 |

### 4. 写稿规矩
- **长度**：440–480 个汉字（配音约 80–90 秒）；一行一短句，空行分段，**一段 = 一句配音**（`tts.py` 按空行切）。
- **第一句就是钩子**：问题、引语或"大反转"，不铺垫。
- **口吻**：懂行的朋友聊天。短句；设问、反转、多用"你"；一句话最多一个数字；少用"当然 / 所以 / 而且"。
- **口径**：指控写"指控"、回应写"回应"，不替任何一方下结论；不确定的用"可能""据报道"。
- **数字**：每个数字都要在 `资料/选题调研.md` 里有出处；实时变化的数字（签名数、榜单）标注"制作时以最新为准"。
- **结尾**：一个开放问题或互动，不问涨跌。
- **标题**：给 3 个，每个 ≤15 字，带悬念或反差（"国产AI，师从美国？""免费开源，才是最狠的生意"）。

### 5. 自查后交稿
输出两个文件，然后**停**：
- `文案_AI生成_v1.md`：3 个标题 + 正文。
- `资料/选题调研.md`：来源表 + 每句的出处对照。

交稿时附一段"逻辑体检"（见 [02_内容与文案规矩.md](02_内容与文案规矩.md)）：开场的直觉是不是真的错、按片子的方法往回推会不会得出相反结论、结尾有没有劝没依据的动作。

你改完或认可后，Agent 把最终版存成 `文案_定稿.md`，后面照常走：配音 → 分镜（先选风格）→ 素材 → 关键帧 → 全片 → 质检。

```

```

```
按 docs/08_文案写作.md 的 B 方式先写稿：调研、选结构、给 3 个标题和文案 v1，
写完停下来等我改。
```
