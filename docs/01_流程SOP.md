# 01 流程 SOP

每一步写清：输入 → 做什么 → 输出 → 谁拍板 → 怎么验收。括号里是第28期的实际情况。

## ⓪ 写稿（只给主题时）
- 用户只给主题时，先按 [08_文案写作.md](08_文案写作.md) 的 B 方式：选题检查 → 调研（`资料/选题调研.md`）→ 选结构 → `文案_AI生成_v1.md`（3 个标题 + 440–480 字）→ 逻辑体检。
- **拍板**：用户改稿或认可，存成 `文案_定稿.md`；核稿只补核用户改动的部分。
- 用户上传了口播稿就跳过这一步，直接核稿。

## ① 核稿（20 分钟）
- **输入**：用户口播稿（`文案_用户原稿_v1.md`，原样保存）。
- **做什么**：逐句找出处。官方公告/文档 > 一手报道 > 二手转载；同一事实多个日期时以官方为准并注明差异。
- **输出**：`事实核对.md`
  - 结论一句话（"没有大的逻辑谬误，也没有明确事实错误，建议按原稿走"）
  - 逐句表：原稿 | 核对 | 处理（不改 / 画面上怎么标）
  - 一句话风险提示（不改稿，但画面要注意的地方。第28期："千问 8→11 月其实也隔了三个月，时间轴要画到今天把'还在等'的空白画出来"）
  - 逻辑体检：开场的直觉是不是稻草人、按片子的方法往回推会不会得出相反结论、结尾是否劝了没研究支持的动作
  - 时长估算（汉字数 ÷ 语速），来源链接
- **拍板**：用户决定改不改稿。

## ② 定稿 + 配音（3 分钟）
- `文案_定稿.md`：空行分段，一段 = 一句配音。
- `tools/tts.py`：按段整段合成（豆包 TTS 2.0，音色刘飞，语速 +20），去头尾静音 → `tts/NN.mp3` + `tts/meta.json`（每句时长）。
- 读音替换写进 `SAY`：`('H200','H二百')`、`('Qwen3.8-Max','Qwen三点八 Max')`、`('6 月','六月')`……
- **验收**：总时长、每句时长打印出来；列出需要用户耳听的词。

## ③ 分镜（30 分钟）
- `分镜_v1.md` 先写**选用风格**：从 [07_风格库.md](07_风格库.md) 选一种（或组合），写清为什么适合、代表视频、和上一期怎么区分（第28期：选 ③ 原件+时间轴，因为题材是一串政策/指控事件 + 五家发布时间对比）。都不合适才提新风格，出 2–3 版关键帧给用户选。
- 然后三部分：
  1. **这期怎么做**：核心意象；颜色表（色值 / 代表什么 / 为什么是它）；"段 → 画面语言"表（相邻两段不能是同一种）；主线路径（一句话写清画面怎么一路往前走，不回第 0 帧）。
  2. **逐句分镜**：# | 时间 | 口播 | 画面 | 动效/运镜 | 为什么这样配。
  3. **要找的素材**（计划，不先下）、**制作时间**、**要你定的**。
- **拍板**：用户过了画风和主线（第28期：双色 + 时间轴通过，第 6 句改用练习册比喻 → `分镜_v2.md`）。

## ④ 素材（40 分钟）
- 视频：`yt-dlp` 下官方发布片、新闻片段、产品片（只要 1080p 以内）；看 `fsheet.py` 缩略图挑入点。
- 空镜：Mixkit（可直接下）；Pexels/Pixabay 会 403。
- 网页原件：`film/webhl.mjs`（原句高亮、英文就地换中文、关浮窗），配置写在 `film/cuts/*.json`。
- 官方发布页：`film/shot_page.mjs` 截页头。
- 实测：要展示"模型回答"时用真模型跑原话（`tools/doubao_qa.py`），不编。
- **输出**：`素材清单.md`（文件 / 内容 / 用在 / 取段）+ 核对补充（找素材时发现的新事实）。

## ⑤ 关键帧（40 分钟）
- `film/kit.js`（本期颜色和组件）+ `film/kf.js`（`renderKF(n)`）→ `node shot_kf.mjs 2 61 62 9 13 19 20`。
- 6–8 张，挑不同段落；拼 `关键帧总览_v1.jpg`，自查后先自己改一轮（第28期改了：时间轴旗子标签重叠、H200 画面太糊、OpenAI 页面文字太密）。
- **拍板**：用户过关键帧。

## ⑥ 全片（写代码 1–2 小时 + 渲染 17 分钟）
1. `python tools/words_all.py` → `tts/words.json`（每句逐字时间；先不带提示词识别，对不上再带提示）
2. `python tools/gen_timeline.py` → `tts/timeline.json`、`film/timeline.js`（字幕屏和每个字的时间；覆盖率 < 85% 报错）
3. `film/shots.js` 写镜头表 → `node tools/prep.mjs` 抽帧到 `film/seq/<镜头>/`
4. `film/scenes.js` 写每个镜头 `D.<镜头id> = t => {...}`；`render(t)` 统一加字幕和角标
5. `node render.mjs stills 1 3 5 8 …` 抽检查帧，`tools/grid.py` 拼网格，逐段看
6. `bash tools/build_v1.sh`：两路并行渲（0–47.5 秒 / 47.5 秒–结尾）→ 拼接 → `score.py` 合成音轨（-14 LUFS）→ 成片

## ⑦ 质检（见 05_质检.md）
闷点 → 字幕对时 → 帧数 → 抽帧总览。有问题用 `patch.sh` 局部补渲。

## ⑧ 交片
成片路径 + 质检结果 + 改过什么 + 耳听清单。用户看完再做封面、发布文案。
